# SHAP Analysis of Aging Index

[Repository overview](../../README.md) · [Bituminous mastic](../README.md)

This folder contains the SHAP (SHapley Additive exPlanations) analysis developed for interpreting the Gaussian Process Regression (GPR) model used to predict the Aging Index of bituminous mastics.

## Analysis

SHAP is applied to quantify the contribution of the model input variables to the predicted Aging Index.

The interpreted input variables are:

- Filler type
- Filler-to-bitumen ratio by mass
- Logarithm of angular frequency

The analysis uses the final trained GPR model to evaluate how these variables influence model predictions.

## SHAP Method

The interpretation is performed using Kernel SHAP.

The experimental dataset is used as the SHAP background dataset, and SHAP values are calculated for the observations used in the analysis.

A prediction wrapper is used to ensure that the input representation used by SHAP is correctly converted to the format expected by the trained GPR model.

## Outputs

The notebook generates:

- SHAP values for the model input variables
- Additivity verification
- Global feature importance
- SHAP summary plot
- SHAP feature-importance bar plot
- Mean SHAP contribution by filler type
- Excel file containing the numerical SHAP results

## Model Interpretation

The SHAP analysis provides both global and feature-level interpretation of the GPR predictions.

Global feature importance is calculated from the mean absolute SHAP values, allowing the relative influence of filler type, filler-to-bitumen ratio, and frequency on the predicted Aging Index to be examined.

## Reproducibility

The SHAP notebook loads the experimental dataset and the previously trained GPR model.

This allows the interpretation analysis to be executed separately from the GPR training notebook, provided that the required dataset and saved GPR model are available.
