# Execution and reproducibility guide

[Repository overview](../README.md)

This guide covers the inputs and execution setup expected by the existing notebooks. Google Colab is the primary workflow: several notebooks use `/content` paths or Colab-specific functionality.

## Prepare a Colab runtime

1. Open a notebook using the [notebook index](../README.md#notebook-index). Save a copy to your own Drive if you want to retain your session and outputs.
2. Connect to a Python 3 runtime.
3. Add a setup cell before the analysis cells and run:

```python
%cd /content
%pip install numpy pandas matplotlib seaborn scipy scikit-learn openpyxl joblib shap deap pyswarms
```

These packages cover the imports and Excel I/O used across the repository. Package versions are unpinned; record the versions actually used with your results. If Colab requests a runtime restart after installation, restart and run the cells again in order.

`deap` and `pyswarms` support the mortar GA/PSO notebook, `shap` supports the interpretation workflows, and `openpyxl` supports the Excel files. Some notebooks include additional setup commands in their own cells.

## Input files

Download the required Excel file from GitHub, then use Colab's **Files** panel to upload it. Retain its exact filename, including spaces and capitalization. Opening a notebook from GitHub does not itself put the repository's Excel files into the Colab runtime.

| Analysis | Required input | Location in the runtime |
| --- | --- | --- |
| Hydrometallurgy | Data embedded in the notebook | No external data file |
| Briquette | Data embedded in the notebook | No external data file |
| Bituminous-mastic GA/PSO, ANN, GPR, and SVR | [Aging index.xlsx](../Bituminous_Mastic/Aging%20index.xlsx) | `/content/Aging index.xlsx` |
| Bituminous-mastic SHAP | The same Excel file and the trained GPR artifact described below | Both files in `/content` |
| Mortar mechanical properties, including SHAP | [Final.xlsx](../Mortar%28Cement%29/Mechanical_Properties/Final.xlsx) | `/content/Final.xlsx` |
| Mortar gauge factor | Averaged experimental data embedded in the notebook | No external data file |

Keep `/content` as the working directory. Some notebooks open an absolute path; others use a relative filename such as `Final.xlsx` or save their results relative to the working directory.

The bituminous-mastic GPR workflow uses filler type, filler-to-bitumen mass ratio, angular frequency, and Aging Index. The mortar mechanical-property workflows use sludge content, plasticizer dosage, density, maximum flexural stress, and mean compressive strength. See each method's README and the supplied dataset for the relevant variables.

## Execution order

### Independent analyses

The hydrometallurgy and briquette notebooks run using their embedded datasets. The bituminous-mastic GA/PSO, ANN, GPR, and SVR notebooks can each be run after uploading `Aging index.xlsx`.

The mortar mechanical-property notebooks each require `Final.xlsx`. The mortar SHAP notebook fits its GPR models within its own workflow; it does not require a saved model file from the separate mortar GPR notebook.

Run all cells of [GFend.ipynb](../Mortar%28Cement%29/Gauge_Factor/GFend.ipynb) in their existing order. Later cells use results created by earlier cells.

### Bituminous-mastic GPR followed by SHAP

1. Open [GPR.ipynb](../Bituminous_Mastic/GPR/GPR.ipynb), prepare the runtime, and upload `Aging index.xlsx`.
2. Run the GPR notebook to completion. It performs nested Leave-One-Mastic-Out validation and fits the final model using the full dataset.
3. Download the generated model file, `GPR_AgingIndex_FBmass_LOMO_final.pkl`, from the Colab Files panel.
4. Open [SHAP.ipynb](../Bituminous_Mastic/SHAP/SHAP.ipynb). In its runtime, upload both `Aging index.xlsx` and the generated model file to `/content`.
5. Run the SHAP notebook.

The model file is generated by the GPR notebook and is not distributed in this repository. When the two notebooks use different runtimes, transfer the file explicitly and use matching package versions for training and interpretation.

## Figures and fonts

Some notebooks look for a Times New Roman font in `/content`. Where used, upload a font file you are entitled to use, following the filename or font-selection instructions in that notebook. The hydrometallurgy and briquette notebooks look for `/content/TimesNewRoman.ttf` and provide a DejaVu Serif fallback.

## Save the outputs

With `/content` as the working directory, the notebooks write their generated files there. The method-specific READMEs describe their outputs. Download the Excel results, figures, and any saved model you need before ending the runtime.

For the bituminous-mastic GPR notebook, the principal outputs include:

- `GPR_AgingIndex_FBmass_LOMO_results.xlsx`
- `GPR_AgingIndex_FBmass_LOMO_final.pkl`
- `GPR_AgingIndex_LOMO_actual_vs_predicted.png`
- `GPR_AgingIndex_LOMO_residuals.png`
- Per-formulation Aging Index curves

The Excel export includes cleaned data, overall metrics, held-out predictions, per-mastic errors, the final grouped grid search, and plotting data.

## Record the runtime

Run this cell after installing dependencies and keep its output with the analysis results:

```python
import sys
from importlib.metadata import PackageNotFoundError, version

print("Python:", sys.version)
for package in (
    "numpy", "pandas", "matplotlib", "seaborn", "scipy",
    "scikit-learn", "openpyxl", "joblib", "shap", "deap", "pyswarms"
):
    try:
        print(f"{package}: {version(package)}")
    except PackageNotFoundError:
        print(f"{package}: not installed")
```

Also record the repository commit, the input files used, and any runtime settings you changed. Random-state settings are defined in the individual notebooks; retaining the runtime information helps explain differences between runs.

## Troubleshooting

| Symptom | Check |
| --- | --- |
| `FileNotFoundError` for an Excel file | Upload the correct file to `/content`, check its exact filename, and confirm the working directory. |
| Missing `GPR_AgingIndex_FBmass_LOMO_final.pkl` | Complete the bituminous-mastic GPR notebook and transfer its saved model into the SHAP runtime. |
| A later cell reports an undefined variable | Start from the setup and first analysis cell, and resolve any earlier error before continuing. |
| An import or Excel-engine error | Install the packages listed above in the runtime that is executing the notebook. |
| A model search has not yet produced outputs | Check the notebook's progress and errors. Nested cross-validation and optimizer restarts require repeated model fitting. |
| A figure uses a different font | Check the font path and the notebook's fallback or font-selection message. |
